# Étude et expérimentation de 29 algorithmes de Machine Learning

Projet S7 : étude théorique et expérimentale de 29 algorithmes
(régression, classification, clustering, réduction de dimension,
détection d'anomalies, renforcement).

**Auteur :** Fatima Zahra HAJJI (n° 23004519)

## Contenu
- `notebooks/` : notebook Colab
- `data/` : sources des jeux de données
- `figures/` : schémas et graphiques
- `report/` : rapport de synthèse
- `docs/` : consignes

## Exécution
1. Ouvrir le notebook dans Google Colab.
2. `pip install -r requirements.txt`
3. Exécuter les cellules dans l'ordre (graine : `random_state=42`).
